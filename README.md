**EXTRAPOLATION**
The dataset provided by ONS only contained entries for participants up to 100 years old, so just using this would cause my calculations to be a slight underestimate of the official annuity price.
To remedy this, I observed that the mortality rate and age follow a log-linear relationship (which is actually the Gompertz Law of Mortality). This is pictured for males and females in the mortality rate plots.
I could then use the coefficients generated by polyfit to extrapolate data for ages above 100.
